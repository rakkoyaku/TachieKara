# TachieKara（立ち絵から）

表情差分の立ち絵から、**顔アイコン**・**バストアップ**・**ディスプレイ画像（立ち絵＋表情一覧）** をまとめて作る Windows / macOS 用の無料アプリです。

- 基準にする立ち絵で切り抜く範囲を一度決めれば、すべての表情を同じ位置で一括で書き出せます。
- 表情に名前（表情名）を付けると、そのままファイル名やディスプレイ画像の表記になります。
- ディスプレイ画像は、17 種類のテンプレート・19 種類の背景・タイトル・クレジットを組み合わせて作れます。立ち絵の色に合わせた配色にもできます。
- アプリの中から新しいバージョンを確認して、そのまま更新できます。

> **作った画像の権利について**
> 作った画像に含まれる絵の権利は、元の立ち絵の作者・権利者のものです。TachieKara を使っても元の権利は損なわれず、TachieKara の作者は作った画像に何の権利も主張しません。作った画像は、元の絵の権利者が認める範囲で使ってください。

## ダウンロードとインストール

[Releases](https://github.com/rakkoyaku/TachieKara/releases/latest) から OS に合ったものを取ってください。

| OS | ファイル |
|---|---|
| Windows | `TachieKara-win-Setup.exe`（インストール版）／ `TachieKara-win-Portable.zip`（展開して使う版） |
| macOS（Apple Silicon: M1 以降） | `TachieKara-osx-arm64-Portable.zip` |
| macOS（Intel） | `TachieKara-osx-x64-Portable.zip` |

### Windows

`TachieKara-win-Setup.exe` を実行するとインストールされ、スタートメニューとデスクトップにショートカットができます。
署名をしていないため「Windows によって PC が保護されました」と出た場合は、［詳細情報］→［実行］を押してください。

### macOS

> macOS 版は現在、実機での動作確認を進めているところです。うまく動かない場合は Issues で教えてください。

Apple の公証を受けていないため、初回は「開発元を確認できない」と表示されます。

1. zip を展開し、`TachieKara.app` を「アプリケーション」へ移動します。
2. 一度ダブルクリックして警告を閉じます。
3. 「システム設定」→「プライバシーとセキュリティ」の下部にある「このまま開く」を押します。

ターミナルで `xattr -dr com.apple.quarantine /Applications/TachieKara.app` を実行しても開けるようになります。

## アップデート

インストールしたアプリは、起動時に新しいバージョンがないか確認します。顔アイコン／バストアップ／ディスプレイの切り替えの横にある **ⓘ（ソフトウェア情報）** からも確認できます。

1. 新しいバージョンがあると、左上に「新しいバージョン x.y.z があります」と出るので［ダウンロード］を押します。
   変わった部分だけをダウンロードするので、通常はすぐに終わります。
2. ダウンロードが終わると、**次にアプリを起動したときに反映** されます。すぐに反映したいときは［今すぐ再起動］を押してください。

インストーラーをもう一度実行する必要はありません。起動時の確認は、ソフトウェア情報の「起動時に新しいバージョンを確認する」で止められます。

## 通信とデータについて

- TachieKara がインターネットに接続するのは、**新しいバージョンの確認とダウンロード（GitHub）だけ**です。読み込んだ画像や作った画像を送ることはなく、利用状況の収集もしていません。
- 設定（枠の位置・表情名・ディスプレイ画像の設定など）は、このパソコンの中だけに保存します。プロジェクトは、保存するときに選んだ場所にだけ作られます。背景に使う自分の画像は、設定フォルダの `backgrounds` にコピーして保管します。
  - Windows: `%APPDATA%\TachieKara\settings.json`
  - macOS: `~/.config/TachieKara/settings.json`

## 困ったときは

- アプリが落ちた場合は、上の設定フォルダにある `crash.log` に原因が記録されます。
- 不具合の報告や要望は [Issues](https://github.com/rakkoyaku/TachieKara/issues) へどうぞ。`crash.log` の内容や、OS・アプリのバージョン（ⓘ で確認できます）を添えていただけると助かります。

## 使い方

1. 立ち絵の画像（またはフォルダ）をウィンドウにドロップするか、［ファイルを追加…］［フォルダを追加…］で読み込みます。
   - フォルダは直下の画像だけを読み込みます（png / jpg / webp / bmp）。子フォルダは必要ならフォルダごと追加してください。
2. 一覧の中から基準にする画像を **★ベース** にします（最初の1枚が自動でベースになります。［★ ベースにする］や右クリックメニューで変更）。
   - ベースと縦横サイズが違う画像には **⚠** が付きます。作成時に「除外する／含める」を選べます。
3. プレビュー上の正方形の枠を顔に合わせます。
   | 操作 | 内容 |
   |---|---|
   | 枠の中をドラッグ | 枠を移動 |
   | 四隅をドラッグ | 枠を拡縮（正方形のまま） |
   | ホイール | 表示の拡大縮小 |
   | Ctrl（Mac は ⌘）+ ホイール | 枠を中心から拡縮 |
   | 枠の外をドラッグ / 右・中ボタンドラッグ / Space+ドラッグ | 表示を移動 |
   | キャンバスをダブルクリック | 全体を表示 |
   | 矢印キー（Shift で 10px） | 枠を 1px ずつ移動 |
   | G キー / ツールバーの［ガイド］ | ガイド線（中心の十字・三分割・円）の表示を切り替え |
   左の素材一覧には、すべての表情の切り抜き結果が小さく表示されます。
   一覧で表情をクリックすると、その表情がキャンバスと右の「仕上がり」に表示されるので、表情ごとにはみ出しがないか確認できます。
4. 右のパネルで出力サイズ（128〜1024 / 原寸 / 任意の px）・背景・フォルダ名などを決めて［顔アイコンを書き出す］を押します。
   - 立ち絵が 1 つのフォルダなら、その中に `顔アイコン` フォルダが作られます。
   - 複数のフォルダにまたがる場合は、作る場所（共通の親 / 各フォルダ / 任意の場所）を選べます。
   - 出力先には切り抜き位置の記録 `crop.json` も保存されます。

### 名前（表情名）を付ける

一覧で画像を **ダブルクリック** するか、選んで **F2**（または左下の［名前］、右クリック →［名前を付ける］）を押すと、その場で名前を入力できます。付けた名前がそのまま書き出すファイル名になります（例: `笑顔` → `笑顔.png`。前後に付ける文字の設定も反映されます）。

- **Enter** で確定、**Esc** で取り消し、**Tab / Shift+Tab** で確定して次／前の画像へ続けて入力できます。入力中はその表情がキャンバスに表示されます。
- 空欄にして確定すると元のファイル名に戻ります。
- 付けた名前は画像ごとに記憶され、次に同じファイルを読み込んだときも残っています。元のファイル名は変更しません。

### バストアップ

右のパネル上部で［顔アイコン］と［バストアップ］を切り替えられます。

- バストアップでは、切り抜くサイズを **幅 × 高さ（px）** で入力し、キャンバスで枠をドラッグして位置を決めます。切り抜いたサイズのまま書き出されます。
- 四隅のドラッグでも大きさを変えられます（Shift を押しながらだと縦横比を保ちます）。
- 書き出し先は `バストアップ` フォルダです（フォルダ名は変更できます）。
- 顔アイコンとバストアップの枠は別々に記憶されるので、切り替えても互いの位置は崩れません。

枠の位置は「ベース画像のフォルダ＋サイズ」ごとに記憶され、同じ立ち絵セットを開き直すと復元されます。

### ディスプレイ画像（立ち絵＋表情一覧）

右のパネル上部の［ディスプレイ］を選ぶと、立ち絵と顔アイコン・表情名を 1 枚に並べた画像を作れます。

- **テンプレート**: 斜め帯／シンプル／カード／ドット／方眼／ストライプ／斜め分割／ダーク／サンバースト／ハーフトーン／ギンガム／ウェーブ／ハニカム／星空／同心円／シェブロン／集中線。［テンプレートを選ぶ］で、プレビューの下に **ギャラリー** が開きます。
  - テンプレートは今のキャラで描いた縮小画像で並びます（キャラを読み込む前は見本の人物で）。押すとその場でプレビューに当たり、［元に戻す］でギャラリーを開いたときの見た目に戻せます。
  - すべて／お気に入り（☆）／最近／標準／マイテンプレート／パックごとに絞り込め、名前で探せます。
  - ［今の見た目を保存］で、マイテンプレートとして保存できます。右クリックで名前の変更・上書き・複製・削除。
- **画像サイズ**: 幅は任意の px、縦横比は 1:1・4:3・3:2・16:9・3:4・9:16・立ち絵に合わせる。PNG / JPG。
- **背景**: 単色・グラデーション・放射・斜め帯・斜め分割・ストライプ・ドット・方眼・チェック・サンバースト・ハーフトーン・ギンガム・ウェーブ・ハニカム・星・同心円・シェブロン・集中線・好きな画像。ギャラリーの「背景」タブで、今の色で描いた縮小画像から選べます（背景だけが替わり、レイアウトや文字はそのまま）。自分の画像は［画像を追加…］で「マイ画像」に入り、アプリの中にコピーして保管されます。色・角度・太さ・位置・濃さを調整でき、ざらつき・周りを暗く・内側の枠線を重ねられます（効果は背景だけにかかります）。
- **立ち絵**: 使う表情、左右、幅・大きさ・位置、白フチ・影、奥に大きく重ねる立ち絵（ゴースト）。透明な余白を除いてから大きさを決めるので、配置の設定どおりに収まります。
- **表情の並び**: 顔アイコンの枠で切り抜いて、左の一覧の順に並べます（載せる表情は一覧のチェックで選び、順番は一覧のドラッグ・∧∨ ボタン・Alt+↑↓ で入れ替えます）。マスの縦横比・引き寄り・列の数・間隔・枠・角の丸み・影・下に敷くカード。
- **表情名**: マスの下／マスの中（帯）／なし。フォント・大きさ・色・フチ、A・B・C の記号。
- **キャラの色**: 立ち絵から目立つ色（髪・服など）を取り出して並べます。押すと今の配色全体の色相をその色の方へ回します（差し色との関係や明るさの組み立てはそのまま）。テンプレートを選んだときに自動で合わせることもできます。
- **タイトル**: キャラクター名と添える文字（例: Expression Sheet）。スタイルは「下線」「プレート」「文字だけ」「縦書き」「透かし（濃さを調整可）」、置き場所は「表情の上・下（左・中央・右揃え）」と四隅。表情の並びや立ち絵と重ならないよう、自動で場所を空けます。
- **クレジット**: 「イラスト：○○」「衣装デザイン：○○」など、描いた人の名前を自由に（複数行も可）四隅のどこかへ小さく入れられます。大きさ・色（自動も可）・濃さ・フォント・下地を調整でき、テンプレートを切り替えても内容は残ります。
- **フォント**: 表情名・タイトル・クレジットで別々に選べます（一覧は日本語フォントだけに絞れます）。

- **テンプレートパック**: 追加のテンプレート集（`.tkpack` ファイル）を、ディスプレイの「テンプレート」→［テンプレートパックを読み込む…］か、ウィンドウへのドロップで読み込めます。読み込んだパックは次回以降もテンプレート欄に並び、ゴミ箱のボタンで外せます。同じパックの新しい版を読み込むと置き換わります。

載せる表情と並び順は、左の一覧のチェックと順番で決まります（表情名は一覧でダブルクリックして付けます）。
長さの設定は画像の幅に対する比率なので、幅を変えても見た目の釣り合いは変わりません。

### プロジェクト（キャラごとの保存）

1 キャラ分の作業を **プロジェクト（`.tachiekara` ファイル）** として保存できます。キャラを切り替えながら作業するときに便利です。

- 左上のプロジェクト欄の［保存］ボタン、または ∨ のメニューから **新規・開く・保存・名前を付けて保存・最近のプロジェクト** を使えます（Ctrl+N / O / S / Shift+S、Mac は ⌘）。
- 保存されるもの: 取り込んだ画像と並び順、表情名、ディスプレイ画像に載せるか、顔アイコン・バストアップの枠、書き出しの設定（出力サイズ・背景・フォルダ名・前後に付ける文字）、ディスプレイ画像の設定。
- **新規** にすると、画像を選ぶ前の最初の画面に戻ります。見た目（テンプレート・背景・レイアウト・文字の設定）と書き出しの設定は引き継ぎ、タイトル・クレジット・使う立ち絵・キャラの色は空になります。
- 保存先は、はじめは立ち絵のフォルダが選ばれます。画像の場所はプロジェクトファイルからの相対位置でも覚えるので、立ち絵のフォルダごと移動しても開けます。
- `.tachiekara` ファイルをウィンドウにドロップしても開けます。最初の画面には最近のプロジェクトが出ます。
- 保存していない変更があるときに新規・開く・（保存したプロジェクトなら）閉じる操作をすると、保存するか確かめます。
- プロジェクトを使わずに、画像を入れてすぐ書き出す使い方もそのままできます。枠の位置や表情名は画像ごとにも覚えているので、同じ画像を入れ直せば元に戻ります。
